Minicurso para front-enders

HTML

O HTML é o alicerce da web. Aprenda a base fundamental de todos os sites: o esqueleto que sustenta todo o conteúdo. Conteúdo do curso: tags fundamentais e estrutura básica, HTML semântico, formulários e entradas de dados, mídia e links.

CSS

O CSS cria páginas com estilo e um design impressionante.

Conteúdo do curso

Transforme estruturas simples em layouts incríveis: cor, layout, responsividade e animações.

  • Sintaxe
  • Seletores e especificidade
  • Modelo de caixa (box model)
  • Layout moderno (Flexbox e Grid)
  • Design responsivo

JavaScript

A mágica da interatividade. Crie experiências dinâmicas e interativas: JavaScript dá vida e lógica às páginas web. Conteúdo do curso: fundamentos e sintaxe, funções e escopo, manipulação da DOM, eventos e interatividade.
